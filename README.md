# Laurea FullStack-kurssin loppuprojekti

Tämä repositorio on luotu Laurean FullStack-kurssin loppuprojektia varten.  
Tässä projektissa on luotu FullStack sovellus hyödyntäen Vercelin tarjoamaa [Next.js kurssia](https://nextjs.org/learn/dashboard-app).   
  
Pääset julkaistuun sovellukseen käsiksi osoitteessa [https://full-stack-projekti.vercel.app](https://full-stack-projekti.vercel.app)
